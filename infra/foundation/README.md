Generated by slipway from `templates/cloud/azure/files/infra/foundation`. Owns the registry, key vault, app identity, log analytics, the Container Apps environment (`cae.tf`, shared by every `infra/apps/<app>`) and the role assignments between them, inside `rg-taskflow-dev` (created by `.slipway/setup-azure.sh`).

| Command | Who |
|---|---|
| `/slipway:plan dev --layer foundation` | anyone; read-only |
| `bash <plugin>/scripts/approve-apply.sh infra/foundation/tfplan.dev` | a human, in a separate terminal |
| `terraform -chdir=infra/foundation apply tfplan.dev` | the session, once, within 10 minutes of the approval |

State: `sttaskflowtf/tfstate/taskflow/foundation/dev.tfstate` (Entra ID auth). Provider needs `ARM_SUBSCRIPTION_ID` in the environment.
